# skills

Agent skills by amr3k.

[![skills.sh](https://skills.sh/b/amr3k/skills)](https://skills.sh/amr3k/skills)

## Install

```sh
npx skills add amr3k/skills
```

`pnpm dlx skills add amr3k/skills` and `bunx skills add amr3k/skills` work too.

## Skills

### issue-to-pr

One task, end to end: find or file the issue, create or reuse the branch, implement in atomic commits, verify end-to-end, push, and open a PR that closes the issue. Re-running reuses whatever already exists instead of duplicating it.

[Read the skill](skills/issue-to-pr/SKILL.md)
